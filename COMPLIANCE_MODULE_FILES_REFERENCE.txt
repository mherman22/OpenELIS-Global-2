CONSTITUTION REQUIREMENTS (From CLAUDE.md)
=============================================================================

Critical Requirements for Services:
  1. @Transactional boundaries ONLY in services (not DAOs, not controllers)
  2. Compile all data within transaction (prevent LazyInitializationException)
  3. DAO methods use @Transactional(readOnly=true) for queries
  4. Services override DAO methods to add business logic

Critical Requirements for DAOs:
  1. @Component annotation (not @Service)
  2. Extends BaseDAOImpl<Entity, String>
  3. HQL only (no native SQL unless critical)
  4. Proper exception handling with LogEvent

Critical Requirements for Forms:
  1. Extends BaseForm
  2. @NotBlank, @Pattern, @Length, @SafeHtml annotations
  3. setFormName() in constructor
  4. Private fields with getters/setters

Critical Requirements for FHIR:
  1. @Component on provider class
  2. Implements IResourceProvider
  3. Proper exception handling (InvalidRequestException, ResourceNotFoundException)
  4. Transform service integration
